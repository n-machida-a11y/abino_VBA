# 📝 工事番号管理システム アップデート手順書

お客様にて以下の手順で更新作業をお願いいたします。
**所要時間：15〜30分程度**

---

## 🎒 事前にご準備いただくもの

当方より以下のフォルダ一式（ZIP）をお送りします：

```
📁 工事番号管理アップデート.zip
  ├── 📁 入力用/           … 現場担当者様のファイル更新用
  ├── 📁 経理用/           … 経理担当者様のファイル更新用
  ├── 📁 管理者用/         … 新規の管理者用ファイル
  └── 📁 マスタ追加シート/ … 「依頼書セル設定」シートのサンプル
```

ZIPを**デスクトップに展開**してから作業を始めてください。

---

## ⚠️ 作業前に必ずやっていただくこと

### ① 全員にファイルを閉じてもらう
作業中は、現場担当者様・経理担当者様・管理者様全員に**ファイルを閉じておいて**いただいてください（作業完了まで）。

### ② バックアップを取る
以下のファイルを **別フォルダ**（例：デスクトップの「旧ファイル_YYYYMMDD」など）にコピーしてください：

- `Z:\全社共有\...\工事番号管理表.xlsm` ← マスタファイル（最重要）
- 各PCの `【全社展開用】工事番号入力管理表.xlsm`
- 経理様PCの `【共有_経理用】請求書作成.xlsm`

もし何か問題があっても、このバックアップがあれば元に戻せます。

---

## 🔧 作業手順

### STEP 1: マスタファイルのパスワード変更

1. `Z:\...\工事番号管理表.xlsm` を開く
2. **「工事番号一覧」シート**を選択
3. 画面上部の **「校閲」** タブ → **「シート保護の解除」** をクリック
4. パスワード入力画面で **`kouji`** を入力 → OK
5. 続けて **「シートの保護」** をクリック
6. パスワード欄に **`3555`** を入力 → OK → 確認入力 → OK
7. 同じ手順で **「その他マスタ」シート** も処理する
8. **Ctrl+S で保存**してから閉じる

### STEP 2: 「依頼書セル設定」シートをマスタに追加

※ マスタに既にこのシートがある場合はスキップ

1. 当方がお送りした `マスタ追加シート/依頼書セル設定.xlsx` を開く
2. シートタブを右クリック → **「移動またはコピー」**
3. 「移動先」で `工事番号管理表.xlsm` を選び、**「コピーを作成する」にチェック** → OK
4. マスタ側で **Ctrl+S で保存**

### STEP 3: 【全社展開用】工事番号入力管理表.xlsm の更新

※ 現場担当者様の各PCで実施、または１台で更新して全台にコピー

1. 対象ファイル（`【全社展開用】工事番号入力管理表.xlsm`）を開く
2. 画面上部にセキュリティ警告が出たら **「コンテンツの有効化」** をクリック
3. キーボードで **`Alt + F8`** を押す（マクロ一覧が出る）
4. リストから **`InstallAll`** を選んで **「実行」**
5. フォルダ選択画面が出るので、デスクトップに展開した **`入力用`** フォルダを選択
6. 「実行しますか？」→ **「はい」**
7. 完了メッセージ（「インストールが完了しました」）が出ればOK
8. **Ctrl+S で保存**

### STEP 4: 【共有_経理用】請求書作成.xlsm の更新

1. 対象ファイルを開く
2. セキュリティ警告 → **「コンテンツの有効化」**
3. **`Alt + F8`** → **`InstallAll`** 選択 → **「実行」**
4. フォルダ選択画面で **`経理用`** フォルダを選択
5. 完了メッセージを確認
6. **Ctrl+S で保存**

### STEP 5: 【管理者用】工事番号管理.xlsm の初期セットアップ

※ 初回のみ必要な作業です

1. `Z:\...\工事番号管理表.xlsm` を **コピー** してリネーム
   - 新しい名前：**`【管理者用】工事番号管理.xlsm`**
   - 置き場所：管理者様の使いやすい場所（例：デスクトップ）
2. コピーした `【管理者用】工事番号管理.xlsm` を開く
3. セキュリティ警告 → **「コンテンツの有効化」**
4. **`Alt + F8`** → **`InstallAll`** 選択 → **「実行」**
5. フォルダ選択画面で **`管理者用`** フォルダを選択
6. 完了メッセージを確認
7. **新しいシートを作成**：
   - シートタブ部分で右クリック → **「挿入」** → 「ワークシート」→ OK
   - 新シート名を **「操作」** に変更（ダブルクリックして編集）
   - シートタブをドラッグして一番左に移動
8. **「操作」シートにボタンを2つ配置**：
   - 画面上部 **「開発」タブ** → 「挿入」→ フォームコントロールの **□ボタン**
     - 【「開発」タブが見えない場合】：
       「ファイル」→「オプション」→「リボンのユーザー設定」→右側の「開発」にチェック → OK
   - シート上で適当な場所にドラッグしてボタンを描画
   - マクロ割当画面で **`マクロ_最新取得`** を選択 → OK
   - ボタンの文字をダブルクリックして **「マスタから最新取得」** に変更
   - 同じ手順でもう1つボタンを作成、マクロ **`マクロ_マスタへ反映`**、ラベル **「マスタへ反映」**
9. **Ctrl+S で保存**して一度閉じる
10. 再度開いて、「操作」シートが自動で開くことを確認

## ✅ 動作確認

以下をお試しください。

### 【全社展開用】の確認
- ファイルを開いて依頼書作成フォームを起動
- いつも通り入力して書き込み → PDF作成
- PDFのファイル名が「宛先_工事名_日付.pdf」の形になっているか

### 【共有_経理用】の確認
- いつも通り依頼NO検索 → 請求書作成

### 【管理者用】の確認
- 開くと「操作」シートが表示される
- **「マスタから最新取得」** を押す → 数秒後「取得完了」メッセージ
- 試しにどこか1箇所編集
- **「マスタへ反映」** を押す → 「反映完了」メッセージ
- マスタファイルを別途開いて、編集が反映されていることを確認

## 🆘 うまくいかない時は

### セキュリティ警告が消えない
「開発」タブ → 「マクロのセキュリティ」で設定を確認

### 「VBAプロジェクトへのアクセスが信頼されていません」と出る
1. 「ファイル」→「オプション」→「セキュリティセンター」→「セキュリティセンターの設定」→「マクロの設定」
2. **「VBAプロジェクトオブジェクトモデルへのアクセスを信頼する」** にチェック → OK

### マクロ `InstallAll` が一覧に見つからない
- ファイルを開き直してみる
- それでも無ければ、ZIPを再展開してやり直し
